HACKHERITAGE 4.0 / BHASHA SETU PIPELINE DOCUMENTATION
================================================================================

1. OVERVIEW & WHAT WORKS
--------------------------------------------------------------------------------
The project provides a lightweight, fast, end-to-end Hindi to Santali (Ol Chiki)
translation, speech-to-text (ASR), and speech synthesis (TTS) system.

[WORKS] 1. Hindi Speech-to-Text (ASR):
        Converts spoken Hindi audio into Devanagari text (`transcript.txt`) using
        a lightweight offline Vosk model (`vosk-model-small-hi-0.22`, 42 MB).

[WORKS] 2. Hindi to Santali Ol Chiki Translation:
        Translates Hindi text into native Santali Ol Chiki script (`transcript_santhali.txt`)
        and Roman phonetic pronunciations using a 3-Tier Translation Engine with
        the 6,780+ row SQLite `translations.db` database and `aksharamukha`.

[WORKS] 3. Lightweight SIH_Bhasha_Setu Phonetic Language Reading & Audio Synthesis:
        Resolves Ol Chiki Unicode script into clean Roman phonetic pronunciations using
        `SIH_Bhasha_Setu`'s character-level Grapheme-to-Phoneme mapping table
        (`OL_CHIKI_TO_PHONETIC`) and database lookup. Synthesizes clear 24kHz audio
        (`output/santali_output.wav`) in under 2 seconds with ZERO heavy AI model downloads!


2. COMPONENT ARCHITECTURE & HOW IT WORKS
--------------------------------------------------------------------------------

A. Speech-to-Text (ASR)
   - Script: `hindi_voice_to_text.py`
   - Model: `vosk-model-small-hi-0.22` (Local, 42 MB)
   - Process: Captures live microphone audio at 16,000 Hz, decodes spoken Hindi
     sentences via Kaldi recognizer, and appends transcribed text to `transcript.txt`.

B. Hindi -> Santali Translation Engine
   - Script: `translate_hindi_santhali.py`
   - Database: `translations.db` (5.36 MB, 6,780 entries)
   - Process:
     - Tier 1: Full phrase bank & exact DB matching (100% precision for common sentences).
     - Tier 2: Word & token dictionary mapping for verbs, nouns, and pronouns.
     - Tier 3: Aksharamukha phonetic transliteration for proper nouns & out-of-vocabulary words.
   - Output: Generates both Ol Chiki script (`ᱤᱧᱟᱜ ᱧᱩᱛᱩᱢ ᱚᱝᱥᱩ ᱠᱟᱱᱟ ᱾`) and Roman
     phonetic pronunciation (`Injag nyutum Ongsu kana.`) saved to `transcript_santhali.txt`.

C. SIH_Bhasha_Setu Language Reading & Audio Synthesis (TTS)
   - Scripts: `santali_tts.py` & `generate_santali_audio.py`
   - Model / Engine: SIH_Bhasha_Setu Grapheme-to-Phoneme (`OL_CHIKI_TO_PHONETIC`) + `gTTS` / `soundfile`
   - Process:
     - Step 1: Reads lines from `transcript_santhali.txt`.
     - Step 2: Passes text through `get_roman_pronunciation()`, which checks phrase bank,
       `translations.db`, and `OL_CHIKI_TO_PHONETIC` character mapping to guarantee clean,
       natural vocal phonetics.
     - Step 3: Synthesizes audio waveforms at 24,000 Hz with 0.3s pause padding between sentences.
     - Step 4: Exports clean audio to `output/santali_output.wav`.


3. HOW TO RUN THE PIPELINE
--------------------------------------------------------------------------------

1. Run Speech-to-Text (Hindi ASR):
   .\venv\Scripts\python.exe hindi_voice_to_text.py

2. Run Hindi -> Santali Translation:
   .\venv\Scripts\python.exe translate_hindi_santhali.py transcript.txt transcript_santhali.txt

3. Run Santali Speech Synthesis (TTS):
   .\venv\Scripts\python.exe generate_santali_audio.py

4. Run Full TTS Module directly:
   .\venv\Scripts\python.exe santali_tts.py
